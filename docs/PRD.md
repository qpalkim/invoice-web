# 견적서 웹 확인 서비스 MVP PRD

## 🎯 핵심 정보

**목적**: 노션에 입력한 견적서 내용을 클라이언트가 별도 로그인 없이 웹에서 확인하고 PDF로 다운로드할 수 있게 한다.
**사용자**: 노션으로 견적서를 작성하는 1인 사업자/프리랜서(관리자)와, 공유 링크로 견적서를 확인하는 클라이언트.

## 🚶 사용자 여정

```
1. [견적서 목록 페이지] (관리자)
   ↓ 특정 견적서 선택

2. [견적서 상세 페이지] (관리자)
   ↓ "공유 링크 복사" 클릭 → 링크 클립보드 복사 (페이지 유지)

3. [견적서 공개 페이지] (클라이언트, 공유 링크로 접속·비로그인)
   ↓ "PDF 다운로드" 클릭

4. [완료] → PDF 파일 다운로드 완료
```

> 관리자 영역(`/quotes`, `/quotes/[id]`)은 인증 기능을 제외하기로 결정해 별도 로그인 없이 접근한다 (1인 관리자 전용 서비스).

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID         | 기능명              | 설명                                               | MVP 필수 이유                      | 관련 페이지        |
| ---------- | ------------------- | -------------------------------------------------- | ---------------------------------- | ------------------ |
| **[F001]** | 노션 견적서 동기화  | 노션에 입력된 견적서 데이터를 가져와 목록으로 표시 | 서비스의 데이터 원천이자 핵심 가치 | 견적서 목록 페이지 |
| **[F002]** | 견적서 상세 확인    | 관리자가 특정 견적서의 항목·금액 상세를 확인       | 공유 전 내용 검토에 필수           | 견적서 상세 페이지 |
| **[F003]** | 공유 링크 생성      | 견적서별 고유 공개 링크를 생성                     | 클라이언트 열람의 진입점           | 견적서 상세 페이지 |
| **[F004]** | 견적서 웹 열람      | 클라이언트가 공유 링크로 견적서 내용을 웹에서 확인 | 서비스의 핵심 목적                 | 견적서 공개 페이지 |
| **[F005]** | 견적서 PDF 다운로드 | 클라이언트가 견적서를 PDF 파일로 다운로드          | 서비스의 핵심 목적                 | 견적서 공개 페이지 |

### 2. MVP 필수 지원 기능

| ID         | 기능명         | 설명                                         | MVP 필수 이유                                  | 관련 페이지                            |
| ---------- | -------------- | -------------------------------------------- | ---------------------------------------------- | -------------------------------------- |
| **[F011]** | 열람 여부 확인 | 클라이언트가 견적서를 확인했는지 목록에 표시 | 관리자가 후속 연락 시점을 판단하는 최소 데이터 | 견적서 목록 페이지, 견적서 공개 페이지 |

> **[F010] 기본 인증**은 제외 결정 (2026-08-07) — 1인 관리자 전용 서비스라 셀프 회원가입/로그인이 불필요하다고 판단해 인증 기능 자체를 도입하지 않기로 했다.

### 3. MVP 이후 기능 (제외)

- 노션 데이터베이스 다중 연동 관리 화면
- 견적서 승인/거절 등 클라이언트 액션 기능
- 관리자 프로필 상세 관리 (아바타, 자기소개 등)
- 알림(이메일/푸시) 시스템
- 견적서 검색 및 필터링
- 견적서 템플릿/버전 관리

## 🗄️ 데이터 모델

### Quote (견적서, 노션 데이터 캐시)

> 인증 기능을 제외하기로 결정해 관리자 계정(User) 모델과 견적서 소유 관계는 두지 않는다.

| 필드          | 설명                     | 타입/관계        |
| ------------- | ------------------------ | ---------------- |
| id            | 고유 식별자              | UUID             |
| notionPageId  | 원본 노션 페이지 ID      | string           |
| invoiceNumber | 견적서 번호 (노션 Title) | string           |
| clientName    | 클라이언트명             | string           |
| issueDate     | 발행일                   | date             |
| expiryDate    | 유효기간                 | date             |
| status        | 상태 (노션 select 값)    | string           |
| totalAmount   | 총 견적 금액             | number           |
| shareToken    | 공유 링크용 토큰         | string \| null   |
| viewedAt      | 최초 열람 시각           | datetime \| null |

### QuoteItem (견적서 품목)

| 필드         | 설명                | 타입/관계  |
| ------------ | ------------------- | ---------- |
| id           | 고유 식별자         | UUID       |
| notionPageId | 원본 노션 페이지 ID | string     |
| quoteId      | 소속 견적서         | → Quote.id |
| itemName     | 품목명              | string     |
| quantity     | 수량                | number     |
| unitPrice    | 단가                | number     |

- **Next.js 15** (App Router) - React 풀스택 프레임워크

- **React 19** - UI 라이브러리 (최신 동시성 기능)

- **shadcn/ui** - 고품질 React 컴포넌트 라이브러리

- **React Hook Form 7.x** - 폼 상태 관리
- **Zod** - 스키마 검증 라이브러리
