# Task 018: 고도화 기능 통합 테스트

관련 문서: [ROADMAP](../docs/ROADMAP.md) · [PRD](../docs/PRD.md) · [Task 017](./017-dark-mode-audit.md)

## 개요

Phase 5~7(Task 013~017)에서 구현한 사이드바 레이아웃, 목록 대시보드 UI, 목록 공유 링크 복사, 다크모드 지원을 하나의 전체 플로우로 재검증하고, 기존 MVP 핵심 플로우에 회귀가 없는지 확인한다. 이 Task는 신규 코드 작성보다 검증이 중심이며, 검증 중 실제로 발견되는 문제만 보정한다.

## 관련 파일

- 신규/수정 파일 없음(검증 중심). 문제 발견 시 관련 파일만 최소 범위로 수정.

## 구현 단계

1. Playwright MCP로 전체 플로우를 라이트/다크 모드 각각에서 재검증: 사이드바 레이아웃 → 목록(요약 카드) → 목록에서 공유 링크 복사 → 상세 페이지 → 공유 링크 복사 → 공개 페이지 → PDF 다운로드.
2. 데스크톱(1280px)/모바일(390px) 두 뷰포트에서 사이드바 드로어, 목록 복사 버튼, 테마 토글이 함께 정상 동작하는지 확인.
3. 회귀 테스트: 기존 MVP 핵심 플로우(목록 → 상세 → 공유 링크 → 공개 페이지, Task 008-1 대응)가 레이아웃/다크모드 변경 이후에도 깨지지 않았는지 확인.
4. `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` 전체 실행.

- [x] 다크 모드: 위와 동일한 전체 플로우 재검증

- [x] 모바일(390px): 사이드바 드로어, 목록 복사 버튼, 테마 토글 동시 정상 동작

### 실행 결과 (2026-08-10, `npm run dev` → `localhost:3001`, Playwright MCP)

1. **라이트·데스크톱(1280px)**: `/invoice` 목록에서 행 복사 버튼(URL 이동 없이 클립보드 캡처) → `INV-2026-0001` 상세 이동 → 상세 페이지 공유 링크 복사 → 복사된 `/q/{quoteId}` 링크로 공개 페이지 접속 → "PDF 다운로드" 클릭 → `INV-2026-0001.pdf` 다운로드 트리거 확인. 전 구간 콘솔 경고/에러 0건.
2. **다크·데스크톱(1280px)**: 동일 플로우를 `INV-2026-0002`로 재검증 — 목록 → 상세 → 공개 페이지 → PDF 다운로드(`INV-2026-0002.pdf`) 모두 정상, 콘솔 경고/에러 0건.
3. **라이트·모바일(390px)**: 햄버거로 드로어 열기(테마 토글과 동시 노출 확인) → 드로어 메뉴 클릭 시 자동 닫힘 → 카드 복사 버튼 클릭(URL 이동 없이 복사, 카드 본문 클릭 시에만 상세 이동) 회귀 없음 확인.
4. **회귀 — 잘못된 공유 토큰**: `/q/00000000-0000-0000-0000-000000000000` 접속 → `EmptyState`("견적서를 찾을 수 없습니다") 정상 렌더링. 콘솔에 Task 011의 구조화 로거(`존재하지 않거나 유효하지 않은 견적서 ID로 접근`) 경고가 그대로 남아있어 에러 로깅 파이프라인 회귀 없음도 함께 확인.
5. **회귀 — Rate limiting**: `browser_evaluate`로 `/q/{quoteId}`에 40회 연속 `fetch` → **28회 `200`, 12회 `429`**로 전환(Task 011/012에서 검증한 60초당 30회 슬라이딩 윈도우와 일치하는 패턴). 미들웨어가 레이아웃/다크모드 변경 이후에도 정상 동작.
6. `npm run typecheck`, `npm run lint`, `npm run test`(19개 테스트 통과), `npm run build` 순차 실행 — 전부 exit code 0.
