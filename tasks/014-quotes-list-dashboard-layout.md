# Task 014: 견적서 목록 페이지 신규 레이아웃 통합 및 대시보드 UI 고도화

관련 문서: [ROADMAP](../docs/ROADMAP.md) · [PRD](../docs/PRD.md) · [Task 013](./013-admin-sidebar-layout.md)

## 개요

Task 013에서 구축한 사이드바형 관리자 레이아웃 안에서 `src/app/invoice/page.tsx`가 자연스럽게 보이도록 여백/폭을 재검토하고, 총 견적서 수·미열람 건수 등 간단한 요약 카드를 배치해 대시보드 성격을 보강한다. 기존 데스크톱 테이블 뷰 / 모바일 카드 뷰의 반응형 동작과 데이터 표시는 그대로 유지한다.

## 관련 파일

- `src/app/invoice/page.tsx` (수정) — 컨테이너 폭 조정(`max-w-3xl` → `max-w-6xl`), 요약 카드 2개(전체 견적서 수, 미열람 건수) 추가.

## 구현 단계

1. 페이지 상단 컨테이너 `max-w-3xl` → `max-w-6xl`로 확장 (사이드바가 이미 폭을 차지하므로 대시보드 폭 기준으로 재검토).
2. 이미 로드된 `quotes` 배열로 `totalCount`(`quotes.length`), `unviewedCount`(`quotes.filter(q => !q.viewedAt).length`) 계산.
3. 제목 아래·목록 위에 요약 카드 2개를 그리드로 배치(기존 `Card`/`CardContent` 재사용, 새 컴포넌트 분리 없이 페이지 내 인라인 처리).
4. 데스크톱 테이블 뷰 / 모바일 카드 뷰 반응형 동작이 유지되는지 확인.

## 테스트 체크리스트

- [x] 신규 레이아웃 내에서 목록 데이터(견적서 번호·클라이언트·금액·열람 여부)가 정상 표시되는지 확인
- [x] 요약 카드의 전체 견적서 수 / 미열람 건수가 실제 노션 데이터와 일치하는지 확인
- [x] 견적서 클릭 시 상세 페이지(`/invoice/[id]`)로 정상 이동하는지 확인
- [x] 데스크톱(1280px)/모바일(390px) 각각에서 테이블 뷰/카드 뷰가 정상 렌더링되는지 확인

### 실행 결과 (2026-08-10, `npm run dev` → `localhost:3001`, Playwright MCP)

1. 데스크톱(1280px) `/invoice` 접속 → 제목 아래 요약 카드 2개("전체 견적서 1건", "미열람 1건") 정상 표시, 실제 노션 데이터(견적서 1건, 미열람 상태)와 일치 확인.
2. 컨테이너 폭이 `max-w-6xl`로 확장되어 사이드바 레이아웃 안에서 여유 있게 표시됨(테이블 뷰 유지).
3. `INV-2026-0001` 클릭 → `/invoice/[id]` 상세 페이지로 정상 이동 확인(회귀 없음).
4. 모바일(390px) `/invoice` 접속 → 요약 카드 2개가 2열 그리드로 정상 표시, 목록은 기존과 동일하게 카드 뷰로 렌더링됨. 레이아웃 깨짐 없음.
5. 두 뷰포트 모두 브라우저 콘솔 경고/에러 0건.
