# 견적서 웹 확인 서비스

노션에 입력한 견적서 내용을 클라이언트가 별도 로그인 없이 웹에서 확인하고 PDF로 다운로드할 수 있게 하는 서비스입니다.

## 🎯 프로젝트 개요

**목적**: 노션으로 견적서를 작성하는 1인 사업자/프리랜서가 클라이언트에게 공유 링크만으로 견적서를 전달하고, 클라이언트는 로그인 없이 내용을 확인·다운로드할 수 있게 합니다.
**사용자**: 노션으로 견적서를 작성하는 관리자(1인 사업자/프리랜서), 공유 링크로 견적서를 확인하는 클라이언트.

## 📱 주요 페이지

1. **로그인 페이지** - 관리자 이메일/비밀번호 로그인
2. **회원가입 페이지** - 관리자 계정 생성
3. **견적서 목록 페이지** - 노션과 동기화된 견적서 목록, 열람 여부 표시 (관리자 홈)
4. **견적서 상세 페이지** - 견적서 항목·금액 확인 및 공유 링크 생성
5. **견적서 공개 페이지** - 클라이언트가 공유 링크로 접속해 견적서를 확인하고 PDF로 다운로드 (비로그인)

## ⚡ 핵심 기능

- 노션 견적서 동기화 (F001)
- 견적서 상세 확인 (F002)
- 공유 링크 생성 (F003)
- 견적서 웹 열람 (F004)
- 견적서 PDF 다운로드 (F005)
- 기본 인증: 회원가입/로그인/로그아웃 (F010)
- 열람 여부 확인 (F011)

## 🛠️ 기술 스택

- **Framework**: Next.js 15.5.3 (App Router + Turbopack)
- **Runtime**: React 19.1.0 + TypeScript 5
- **Styling**: TailwindCSS v4 + shadcn/ui
- **Forms**: React Hook Form + Zod
- **UI Components**: Radix UI + Lucide Icons
- **Backend/DB**: Supabase (인증, PostgreSQL)
- **외부 연동**: Notion API
- **PDF 생성**: @react-pdf/renderer
- **배포**: Vercel

## 🚀 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 전체 검사 (타입체크 + 린트 + 포맷)

```
